# Проверка первой версии

Проверено в облачной Linux-среде 26 октября 2026:

- `npm ci` — повторная установка по lock-файлу успешна.
- `npm test` — 9 тестов успешно: точность денег, доход/расход, переводы, проверка данных, восстановление, транзакционный откат и параллельные записи.
- `npm run build` — TypeScript и production Vite bundle успешно.
- `CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e` — 2 сценария успешно (1440×1000 и 390×844): доход, расход, новый валютный счёт, перевод, перезагрузка, пользовательская категория, экспорт и восстановление; горизонтального переполнения нет.
- `npm audit --omit=dev` — 0 обнаруженных уязвимостей production-зависимостей на момент проверки.
- `npm run android:sync` и Gradle `assembleDebug` — успешно; создан debug APK, проверена подпись с помощью apksigner.
- Electron cross-packaging Windows x64 — успешно; подготовлен каталог с EXE и зависимостями.

Android APK и Windows EXE **не запускались на целевых устройствах**. На Android отдельно проверить системный диалог экспорта/восстановления, сохранность данных после закрытия приложения, клавиатуру и системные отступы. На Windows проверить первый запуск, экспорт, повторное открытие и установку/обновление.

NSIS installer в Linux не собран: отсутствует Wine. Workflow GitHub Actions содержит отдельную Windows job для сборки установщика и Android job для debug APK. Статус удалённого workflow этим документом не подтверждается.

Скриншоты в этой папке получены браузерным тестом с тестовыми операциями. Реальная база при первом запуске пустая. Дистрибутивы, базы пользователей и ключи подписи в Git не включаются.
